ControlGS is python based desktop application for mapping controller input to keyboard input

ControlGS let users configure controller buttons to Keyboard keys such as W, A, S, D, Space, and Shift so users can use their controllers to play browser based games directly with their controller. It uses pygame to take input from a controller and uses pynput to simulate key presses.
